  • 학업·유흥·체력 계열 몬스터가 서로 다른 게이지를 깎음

  • 2분마다 페이즈 전환, HUD에 레벨 대신 '학년' 표시
  • 캐릭터·몬스터 픽셀 에셋 전부 직접 제작

라운드별 단어 데이터, 사운드·이미지 에셋, 테스트 플레이

90년대 영어 학습 프로그램처럼 시작해서 라운드가 오를수록 화면이 무너지는 게임입니다. 토끼 '버디'의 뜻풀이에 맞는 단어를 눌러 5×5 판에서 3줄을 맞추면 통과합니다.

  1. R1 제한시간 없음, 실패해도 한 번 더
  2. R2 제한시간 추가, 실패하면 하트를 채워 주고 R3로
  3. R3 escape · run · hide 같은 도망 단어를 누르면 정답이어도 하트 감소

단어 75개를 라운드당 25개씩, 일상어에서 기괴한 설명으로 수위가 오르게 배치했습니다. 배분·중복 규칙은 테스트 코드로 확인합니다.
